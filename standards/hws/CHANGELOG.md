# Hardware Write Safety (HWS) changelog

Each version is immutable in its own folder once released. Text changes bump the version. See `0.1/README.md` for the policy.

## 0.1 (working draft)

First record of the requirement list: 56 requirements (50 MUST, 6 SHOULD) in 13 areas, each with rationale, borrowed concepts, verification method and `version_added = "0.1"`.

Not released: there is no `RELEASED` file yet, so the folder may still change. Open questions: reviewers outside the author's companies; a read of the ISO 13850, IEC 62061, UL 1998 and IEC 62745 clauses through a licensed route; a recheck against MHS and the MCP annotation proposals; alignment with MWS once its comment window closes.
